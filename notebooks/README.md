# Notebooks

This folder will contain curated, public-safe notebooks that explain the research workflow without distributing credentialed clinical data or unpublished ensemble details.

Planned notebooks:

1. preprocessing overview;
2. GCN, GAT, and R-GCN model comparison;
3. evaluation and safety analysis.

The original experimental notebooks are intentionally not uploaded directly. Public versions will use portable configuration, cleared outputs, and explicit data-access checks.
